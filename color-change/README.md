# Color Change

A small, dependency-free HTML, CSS, and JavaScript project.

## Run the local server

Open a terminal and run:

```bash
cd /Users/manjit/Desktop/my-projects/javascript-projects/color-change
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your browser. Leave the terminal running while you use the page; press **Ctrl+C** to stop the server.

If port `8000` is already in use, choose another port, for example:

```bash
python3 -m http.server 8001
```

Then visit [http://localhost:8001](http://localhost:8001).
